LESSON 34: when a parent file (vehicle_settings_resolver.go) holds a
*concrete-type* adapter for a child aggregate (*VehicleRepo wired to
VehicleNameLookup interface), the adapter must move INTO the child
subpkg to avoid a parent->child compile cycle. The interface stays in
the parent (resolver still depends only on the interface seam) and the
adapter constructor renames from NewVehicleNameLookup to NewNameLookup
following Go style (package name qualifies — vehicle.NewNameLookup is
preferred over vehicle.NewVehicleNameLookup stutter).
