──────────────────────────────────────────────────────
  Next steps
──────────────────────────────────────────────────────

  1. Provision {{ include "teslasync.secretName" . }} with DATABASE_PASS,
     GRAFANA_ADMIN_PASSWORD, and Tesla credentials, or configure
     externalSecrets. GitOps/offline renders never generate credentials.

  2. For an opt-in chart-managed Secret, set secrets.create=true and
     provide explicit strong passwords:
     --set postgresql.auth.password=<STRONG_PASSWORD>
     --set grafana.adminPassword=<STRONG_PASSWORD>

  3. (Optional) Enable distributed tracing:
     --set config.openTelemetry.enabled=true --set jaeger.enabled=true

  4. (Optional) Enable automated backups:
     Configure via Web UI → Backup & Restore

  5. Run helm tests to verify the deployment:
     helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

  6. Verify image signatures:
     cosign verify ghcr.io/<your-org>/teslasync-api:<tag> \
       --certificate-identity-regexp="github.com/<your-org>" \
       --certificate-oidc-issuer="https://token.actions.githubusercontent.com"
