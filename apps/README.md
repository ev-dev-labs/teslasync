# TeslaSync Native Apps — Contributor Guide

Native, fully-per-platform TeslaSync clients (Windows / Android / Apple) built to
**semantic parity** with the web app (`web/src` is the canonical spec). One repo, one
contract, three native UIs — see
[ADR-001 — Monorepo + `apps/` layout](../.github/prompts/monorepo/adrs/ADR-001-monorepo-layout.md)
and
[ADR-012 — Technology + version lock](../.github/prompts/monorepo/adrs/ADR-012-tech-version-lock.md).

You do **not** need to clone or build the whole monorepo to work on a single platform.
See [Sparse / partial checkout](#sparse--partial-checkout) below.

---

## 1. Map of `apps/`

| Path | What it is |
|---|---|
| `apps/shared/` | Kotlin Multiplatform (KMP) shared core — networking, SSE, units, cache, generated API client; consumed by Android + Apple (ADR-004). |
| `apps/design/` | Cross-platform design tokens (`tokens.schema.json`) mapped to Fluent / Material 3 / HIG (ADR-005). See [`design/README.md`](design/README.md). |
| `apps/parity/` | Machine-checkable parity spine: `manifest.schema.json` + per-platform ledgers that gate "DONE" (ADR-006/011). See [`parity/README.md`](parity/README.md). |
| `apps/windows/` | WinUI 3 / .NET 10 app. Central package versions in `Directory.Packages.props`. |
| `apps/android/` | Jetpack Compose / Material 3 app. Version catalog in `libs.versions.toml`. |
| `apps/apple/` | SwiftUI macOS + iOS/iPadOS app. Pins in `apple/versions.lock.md`. |
| `apps/tools/` | Repo tooling — placeholder/stub gate (`check-placeholders.ps1`, `placeholder-patterns.json`) per ADR-011. |
| `apps/docs/` | Cross-cutting runbooks: [`authentik-native-clients.md`](docs/authentik-native-clients.md), [`observability.md`](docs/observability.md). |
| `apps/versions.lock.md` | Toolchain + dependency version lock for every platform (ADR-012). |
| `apps/.editorconfig` | Shared formatting rules across languages. |

## 2. Sparse / partial checkout

Work on one platform without materializing the entire tree. From a fresh clone:

```bash
git clone --filter=blob:none --no-checkout https://github.com/ev-dev-labs/teslasync.git
cd teslasync
git sparse-checkout init --cone
# Windows track (swap apps/windows for apps/android or apps/apple as needed):
git sparse-checkout set apps/shared apps/design apps/parity apps/windows api/openapi
git checkout
```

Every platform needs `apps/shared`, `apps/design`, `apps/parity`, and the `api/openapi`
contract; add only your platform directory. Switch platforms by re-running
`git sparse-checkout set …` with a different `apps/<platform>` directory.

> `api/openapi/` is generated by the P1 Shared program; if it is not yet present on your
> branch, regenerate it (see [Where the contract lives](#5-where-the-contract-lives)).

## 3. Per-platform dev setup

Exact versions are locked in [`versions.lock.md`](versions.lock.md) (ADR-012). Renovate
keeps patch versions current; major bumps require a superseding ADR.

### Windows
- Visual Studio 2022+ (17.x) with the **WinUI / Windows App SDK** workload.
- **.NET 10 SDK** (LTS).
- **Windows App SDK 2.1.3** (1.6+ runtime).
- CommunityToolkit.Mvvm 8.2.1. Package versions are centralized in
  `windows/Directory.Packages.props`.

### Android
- **JDK 17+**.
- Android Studio (current) with **Android SDK** — `minSdk 26`, `targetSdk 36`.
- **Gradle 8.14.5**, AGP 8.4.0, Kotlin 2.4.0, Compose BOM 2026.04.01, Material 3 1.4.0.
  Versions are pinned in `android/libs.versions.toml`.

### Apple
- **macOS** + **Xcode 26** (current; SwiftUI/Swift Charts/MapKit are SDK-bundled).
- **Swift 6.0.1** (strict concurrency).
- Dependencies via **SPM** (CocoaPods only where SPM is unavailable). Pins in
  `apple/versions.lock.md`.

## 4. Build / lint / test (the ADR-010 triad)

Each platform runs the native **build + lint/format (strict) + tests** triad and captures
`EXIT=`. Run these from the repo root (see
[ADR-010 — Testing gates](../.github/prompts/monorepo/adrs/ADR-010-testing-gates.md)):

| Step | Shared (KMP) | Windows | Android | Apple |
|---|---|---|---|---|
| Build | `gradlew :shared:build` | `dotnet build -c Release` | `gradlew assembleDebug` | `xcodebuild build` |
| Lint/format | ktlint / detekt | `dotnet format --verify` + WinUI analyzers | ktlint / detekt + Android Lint | `swiftlint --strict` + `swiftformat --lint` |
| Unit tests | `gradlew :shared:test` | `dotnet test` | `gradlew test` | `xcodebuild test` |
| UI tests | — | WinAppDriver | Compose UI test / Espresso | XCUITest |

Coverage target is ≥80% on shared core + per-platform logic, including each parity unit's
loading / empty / error states. A gate that cannot run (missing SDK/device/runner) is
**BLOCKED**, never DONE. Before any UI is marked done, the placeholder gate must pass:

```powershell
pwsh apps/tools/check-placeholders.ps1
```

## 5. Where the contract lives

The Go API is the single source of truth. It emits an **OpenAPI 3.1** document at
`api/openapi/teslasync.openapi.json`, and **all** client models + API call code are
**generated** from it — never hand-written (see
[ADR-003 — OpenAPI source of truth](../.github/prompts/monorepo/adrs/ADR-003-openapi-source-of-truth.md)).

Regenerate clients after the contract changes (generators pinned in
[`versions.lock.md`](versions.lock.md)):

- **Kotlin** (KMP shared core) — `openapi-generator` 7.6.0.
- **C#** (Windows) — NSwag 14.7.1 / Kiota 1.24.0.
- **Swift** (Apple) — `swift-openapi-generator` 1.2.0.

Never edit generated client code by hand — change the Go API, regenerate the OpenAPI
document, then regenerate the clients.
