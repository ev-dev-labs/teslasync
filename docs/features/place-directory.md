# Place Directory

`/geofences` shows saved places and a review queue of unmatched visited places. The candidate feed groups the latest 5,000 completed drive endpoints into 75 m neighborhoods. Completed charging sessions within 75 m provide independent charging evidence; no charging observation is labeled as unobserved, not proof that a place cannot charge. The feed is read-only and shows up to 100 proposed places. A candidate becomes a saved, enabled place only after the user confirms its name, coordinates, radius, and charging purpose.

Confirmed charging sessions can also auto-create provisional, disabled places in **Needs Setup**. Review and save the purpose and name, then **Mark reviewed & enable** to activate them. All reviewed places are enabled; the directory has no enable/disable switch. Previously disabled reviewed places are enabled by migration `000251`, while pending-review places remain disabled and cannot trigger entry/exit alerts before review. Previously configured entry/exit alert flags on disabled reviewed places are preserved and become active when those places are enabled; check existing alert rules before deployment. Archive a place to retire it; unarchiving restores the reviewed/pending enabled state. Configure entry and exit notifications per place in **Notifications → Alert Studio**; pending-review places cannot enable these alerts. Editing a place's directory details never overwrites its notification flags. Saved place names resolve by spatial match before external reverse geocoding. Drive/charge attribution uses the same geofence directory, and visited-location aggregates prefer the current saved name over a drive's original geocode.

For charging places, the initial rate defaults to midnight on the *local calendar day before* the earliest matching charging session, including unpriced sessions and spatially matching unattributed history. Saving a rate does not automatically reprice older sessions: preview and explicitly apply the rate to eligible sessions. Actual/manual costs remain protected.
